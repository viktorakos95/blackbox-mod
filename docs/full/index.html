blackbox-mod patcher

Unofficial mod for the original 1010music Blackbox. Pick the parts you want, give the page your own stock 3.1.9 BLACKBOX.bin, and it makes the patched file in your browser. Nothing is uploaded.

Not tested on a real unit for most of this. The combinations are tested in an emulator; several features have never run on hardware. Keep your stock file: it is your way back.

2. Your stock file

Download blackbox 3.1.9 from 1010music.com/downloads, unzip it, and choose the BLACKBOX.bin inside.

Then copy the patched file to the root of the microSD card as BLACKBOX.bin and install it like any firmware update (hold BACK + INFO while powering on). To go back, install the stock file the same way.
