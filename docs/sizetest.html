Firmware size test

This checks whether your Blackbox refuses firmware files above a certain size. All three files are the unchanged stock 3.1.9 with empty bytes added at the end, which the firmware never reads. Only the size differs.

1. Choose your stock 3.1.9 BLACKBOX.bin (from 1010music):

2. For each file, A, then B, then C:

  1. Copy it to the root of the card and rename it to BLACKBOX.bin.
  2. Install it the usual way (hold BACK + INFO while powering on).
  3. Write down if it installs or says "unable to verify".

Each one is stock 3.1.9, so your unit works normally whichever one installs. When you are done, install your normal stock file again.
