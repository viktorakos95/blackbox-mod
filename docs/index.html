blackbox-mod patcher

Unofficial mod for the original 1010music Blackbox. What it adds, source, known issues.

Want to hear when a new build is out? Get new builds by email.

  1. Download blackbox 3.1.9 from 1010music.com/downloads and unzip it.
  2. Choose the BLACKBOX.bin from that zip below. Keep that stock file as your backup.
  3. Copy the patched file to the root of the microSD card as BLACKBOX.bin and install it like any firmware update.
The file is patched in this page. Nothing is uploaded.
