blackbox-mod patcher

Unofficial mod for the original 1010music Blackbox, firmware 3.1.9. Pick what you want, choose your own stock BLACKBOX.bin, and the patched file is made in your browser. Nothing is uploaded.

Experimental, little tested on real units. The patched file is about 1.7 MB (stock is 0.7 MB) and some installers may refuse it ("unable to verify" or "firmware not found"): copy it to the card again, and if it still fails, install your stock file.

What's new

    Parts

    SONG steps through the pages you pick in this order: Looper, SAMPLR, Trigger2MIDI, DRONE-8, MCL, then the normal song screen. BACK steps back. Settings are saved with your project (SAVE on the Looper's SETUP page, SAMPLR and DRONE-8).

    Diagnostics

    Your stock file

    Get blackbox 3.1.9 from 1010music.com/downloads and choose the BLACKBOX.bin inside.

    Blackbox says "unable to verify" or "firmware not found"?
    • The file on the card must be named BLACKBOX.bin, in the card's root folder, and be exactly the size shown above. A shorter file means the copy went wrong: copy it again, ideally with a different card reader or card.
    • If it still fails, put your stock file back, then copy the details below and send them to whoever gave you this link, with your Blackbox's firmware version before the update, the type of card, and the exact message you got.

    Install: copy it to the card root as BLACKBOX.bin and update as usual (BACK + INFO at power-on). Keep the stock file to go back.
